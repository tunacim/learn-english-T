# Curriculum (Müfredat) · A1–A2

Topics in teaching order. `dashboard.py` reads this table; keep the columns and the `id` values stable.
A topic depends on the topics before it in the same unit. Vocabulary (Kelime) topics run in parallel with the grammar of their unit.
Unit `K` = vocabulary tracks (kelime yolları): they run in every session, next to any unit, and have no level (`—`).
Writing (capital letters, punctuation) is not a topic: it is only noted with the `yazim` tag (SKILL.md § 5).
Sources: British Council LearnEnglish A1–A2 grammar, ExamEnglish A1/A2 lists, CEFR descriptors; Turkish L1 errors from Erciyes and Bilkent corpus studies.
